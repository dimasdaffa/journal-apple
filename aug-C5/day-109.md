#### 🎨 1. UI/UX Guiding Action: The Grayscale Accessibility Test

Tim menguji ketergantungan visual desain menggunakan filter monokrom (*Grayscale Color Filter*) untuk memastikan antarmuka tetap informatif bagi pengguna dengan *low vision*, buta warna, maupun saat *display styling* berubah:

* **Eliminasi Ketergantungan Warna (*Beyond Color as Identifier*):**
* **Rating & Feedback Stars:** Tidak hanya mengandalkan warna kuning vs abu-abu; menggunakan perbedaan bentuk tegas (*filled icon* vs *outline stroke*) dan teks pendukung jumlah bintang.
* **Toggles & State Switches:** Menambahkan penanda teks eksplisit (**ON / OFF**) atau simbol visual `I / O` di dalam *switch* selain perubahan warna latar.
* **Form Validation & Error States:** Mengganti validasi *border* merah dengan ikon peringatan visual, pesan kesalahan teks langsung di bawah *field* (*inline helper text*), dan getaran *Haptic Feedback*.
* **Status & Pilihan Ganda:** Menggunakan kombinasi bentuk *checkbox/radio mark* dan ketebalan garis, bukan sekadar warna hijau (benar) dan merah (salah).
* **Pagination & Progression:** Menambahkan indikator angka eksplisit (*"Halaman 1 dari 3"*) atau *stepper bar* dengan perbedaan bentuk ketimbang *dot* berwarna.

#### 🗺️ 2. Penyusunan First-Time User Flow

Tim memetakan arsitektur navigasi awal aplikasi (*User Journey*) dari saat aplikasi pertama kali dibuka hingga pembacaan naskah:

```text
[Onboarding & How-To Audio] ➔ [Homepage / Dashboard]
                                    │
         ┌──────────────────────────┴──────────────────────────┐
         ▼                                                     ▼
[Script Library & Search]                             [Upload File to Scan]
         │                                                     │
         │                                            [File Picker (PDF/Img)]
         │                                                     │
         │                                            [Loading & AI Parser]
         │                                                     │
         │                                          ┌──────────┴──────────┐
         │                                          ▼                     ▼
         │                                      [Success]              [Fail]
         │                                          │                     │
         └──────────────────► [Script Detail View] ◄┘             [Pop-up Retry]
                                     │                              (Yes ➔ Reload)
                             ┌───────┴───────┐                      (No  ➔ Home)
                             ▼               ▼
                      [Screen Reader]    [Voice Edit / Cues]

```

* **Poin Kunci Alur:**
* **Onboarding Aksesibel:** Panduan suara singkat (*spoken instruction*) di awal untuk mengenalkan gestur dasar aplikasi bagi pengguna VoiceOver.
* **Ingestion Terfokus:** *File picker* dioptimalkan untuk PDF naskah dan foto kamera.
* **Resilient Error Handling:** Jika proses OCR gagal, sistem menyediakan dialog *retry* yang jelas dengan navigasi suara tanpa membuat pengguna tersesat (*dead-end*).
* **Script Detail Hub:** Halaman utama naskah langsung membagi fokus ke dua aksi: *Screen Reader Playback* dan *Edit/Voice Rehearsal Notes*.
